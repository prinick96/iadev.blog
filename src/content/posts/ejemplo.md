## Encabezados

En primer lugar, es fundamental establecer una jerarquía clara. Los encabezados permiten organizar la información, facilitar la exploración del documento y proporcionar referencias útiles para la navegación. En un contenido generado con IA, esta organización ayuda a transformar una respuesta extensa en una secuencia de apartados comprensibles.

El título del artículo ya ocupa el nivel uno. Por tanto, el contenido comienza en el nivel dos y utiliza los niveles siguientes para desarrollar aspectos cada vez más específicos.

```markdown
# Guía integral de contenido Markdown con IA

## Planificación del contenido

### Definición de objetivos

#### Criterios de calidad

##### Revisión de ejemplos

###### Observaciones complementarias
```

### Definición de objetivos

El primer paso consiste en determinar qué se quiere comunicar y a quién se dirige el contenido. Esta definición permite orientar la generación de ejemplos y mantener un enfoque consistente a lo largo del documento.

#### Criterios de calidad

Es importante destacar que la claridad, la precisión y la accesibilidad deben considerarse de manera conjunta. Un contenido bien estructurado facilita tanto la lectura inicial como las revisiones posteriores.

##### Revisión de ejemplos

Los ejemplos deben ser representativos del uso previsto y presentar suficiente variedad para evaluar la apariencia de cada elemento. Asimismo, conviene comprobar que su interpretación no dependa de información externa innecesaria.

###### Observaciones complementarias

Este último nivel permite añadir detalles específicos dentro de una jerarquía ya establecida. Su utilización debe responder a una necesidad real de organización del contenido.

**En síntesis:** una estructura progresiva ofrece una base sólida para desarrollar documentos claros, consistentes y fáciles de recorrer.

### Go: organización de documentos

Este ejemplo utiliza una estructura de datos, una colección y un criterio de ordenación. De este modo, permite observar el resaltado de tipos, funciones, cadenas y valores numéricos dentro de un mismo bloque.

```go
package main

import (
    "fmt"
    "sort"
)

type Document struct {
    Title    string
    Priority int
}

func main() {
    documents := []Document{
        {Title: "Guía de contenido con IA", Priority: 2},
        {Title: "Criterios de revisión", Priority: 1},
    }

    sort.Slice(documents, func(i, j int) bool {
        return documents[i].Priority < documents[j].Priority
    })

    for _, document := range documents {
        fmt.Printf("%d — %s\n", document.Priority, document.Title)
    }
}
```

### Python: preparación de resúmenes

A continuación se presenta un ejemplo con una clase de datos y una función que transforma una colección. La combinación permite revisar la legibilidad de anotaciones de tipos, comprensión de listas y cadenas formateadas.

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class Document:
    title: str
    section_count: int
    review_required: bool = True


def summarize_documents(documents: list[Document]) -> list[str]:
    return [
        f"{document.title}: {document.section_count} secciones"
        for document in documents
    ]


documents = [
    Document("Planificación del contenido", 4),
    Document("Revisión de ejemplos", 3),
]

for summary in summarize_documents(documents):
    print(summary)
```

### Bash: comprobación de un archivo

El siguiente fragmento comprueba si existe el archivo de ejemplo y muestra un mensaje según el resultado. Incluye un bucle, una condición y una salida de error para ampliar la variedad de sintaxis representada.

#!/usr/bin/env bash

for step in \
  'Preparar la revisión' \

### JavaScript: transformación de información

Este ejemplo organiza secciones y calcula el número de apartados que requieren revisión. Su estructura permite comprobar funciones de flecha, acceso opcional y operadores de uso habitual.

```js
const sections = [
  { title: "Introducción", review_required: true },
  { title: "Ejemplos técnicos", review_required: true },
  { title: "Referencias", review_required: false },
];

const outline = sections.map((section, index) => ({
  position: index + 1,
  title: section.title,
  review_required: section.review_required,
}));

const pendingCount = outline.filter(
  (section) => section.review_required,
).length;
const firstTitle = outline[0]?.title ?? "Sin secciones";

console.log({ outline, pendingCount, firstTitle });
```

### TypeScript: contratos de revisión

TypeScript permite expresar de forma explícita la estructura de los datos y los posibles resultados de una operación. En este ejemplo, la revisión se limita a comprobar si el título contiene texto; no representa una evaluación completa de la calidad editorial.

```ts
type Document = {
  title: string;
  generated_by_ai: boolean;
  review_required: boolean;
};

type Review<T> = { valid: true; data: T } | { valid: false; error: string };

function checkDocumentTitle(document: Document): Review<Document> {
  if (document.title.trim().length === 0) {
    return { valid: false, error: "El documento debe incluir un título." };
  }

  return { valid: true, data: document };
}

const review = checkDocumentTitle({
  title: "Guía de contenido Markdown",
  generated_by_ai: true,
  review_required: true,
});

if (review.valid) {
  console.log(review.data.title);
} else {
  console.error(review.error);
}
```
